El proyecto Aula Virtual UNI es una aplicación desarrollada en C# dentro del entorno .NET y se organiza utilizando una arquitectura por capas que separa claramente las entidades, el acceso a datos y la interfaz principal. La solución contiene el directorio Entities, donde se encuentran las clases que representan los modelos del sistema, como usuarios, cursos, tareas, proyectos y roles, los cuales permiten estructurar la información y mantener coherencia en toda la aplicación. En el directorio AulaVirtualDAL se desarrolla la capa de acceso a datos responsable de establecer la conexión con la base de datos, ejecutar consultas SQL, manejar repositorios y realizar las operaciones CRUD necesarias para gestionar la información del aula virtual. Por su parte, el directorio Aula_Virtual_UNI constituye la capa principal, donde se integra la interfaz del usuario junto con la lógica de negocio; aquí se administran formularios, controladores, validaciones y elementos visuales apoyados por recursos estáticos como HTML, CSS o JavaScript según el entorno utilizado. En cuanto a su funcionalidad, el sistema ofrece una plataforma académica que permite registrar y gestionar usuarios, asignar roles como estudiante o profesor, administrar cursos, crear y organizar proyectos, manejar tareas o actividades académicas, visualizar información relevante del curso, cargar o consultar recursos, y facilitar la interacción entre docentes y estudiantes mediante una estructura clara y centralizada. También permite la gestión administrativa del aula virtual mediante operaciones como el mantenimiento de información, la organización del contenido educativo y la verificación de datos registrados en la base de datos. En conjunto, el proyecto funciona como un sistema académico completo que centraliza la información y actividades de un entorno educativo virtual, permitiendo su operación a través de Visual Studio tras clonar el repositorio, restaurar dependencias, configurar la cadena de conexión en la capa de datos y ejecutar la solución. Esta arquitectura facilita el mantenimiento, la escalabilidad y la comprensión del proyecto, siguiendo buenas prácticas de desarrollo en .NET.
